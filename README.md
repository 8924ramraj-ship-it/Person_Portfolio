# Omprakash Vishwakarma Portfolio — Stage 1

This delivery implements the approved **Editorial / Modern Journal** visual direction and the Home page.

## Included
- `index.html` — Home page
- `css/theme.css` — shared colour system, typography, layout and responsive rules
- `js/main.js` — theme toggle, mobile navigation and restrained reveal behaviour
- `images/profile-placeholder.svg` — temporary portrait frame artwork

## Approved design system
- Warm ivory: `#EDE9DF`
- Charcoal: `#292D27`
- Muted olive: `#68745A`
- Clay accent: `#A96F53`
- Secondary neutral: `#E4DFD3`
- Heading font: Cormorant Garamond
- Body/UI font: DM Sans
- Light and dark themes; preference saved in localStorage
